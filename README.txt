=== DeepSeek — InlineAdmin v0.85 ===

🤖 AI чат-бот с поддержкой нескольких режимов общения и генерации изображений

📋 Основные возможности:
• 💬 Умный диалог с ИИ (DeepSeek, Mistral, OpenChat, Llama)
• 🎭 4 режима общения (нормальный, грубый, берсерк, пошлый)
• 🧩 Персональные режимы с собственными промптами
• 🎨 Генерация изображений (Gemini, Flux, DALL-E)
• 🖼 Массовая генерация изображений для админа
• 👥 Работа в группах и личных чатах
• 🛠 Полноценная админ-панель
• 👑 Спонсорская система
• 🔑 Умная ротация API-ключей

🔧 Команды:
/start       — запуск бота и главное меню
/help        — справка по командам
/clear       — очистить историю диалога
/draw        — генерация изображений
/groupmenu   — меню настроек группы

👑 Админ-команды:
/admin       — панель управления
/stats       — быстрая статистика
/ban <id>    — бан пользователя
/unban <id>  — разбан пользователя
/bangroup    — бан группы

⚙️ Настройка:
1. Создай .env файл с переменными:
   TELEGRAM_TOKEN=ваш_токен_бота
   AI_API_KEYS=ключи_api_через_запятую
   ADMIN_ID=ваш_telegram_id
   
2. Установи зависимости: pip install -r requirements.txt
3. Запусти: python bot.py или start.bat

💡 Важно: в @BotFather отключи privacy (/setprivacy -> Disable), чтобы бот видел сообщения в группах.
